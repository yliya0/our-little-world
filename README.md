# Маленькое место для нас ♡

## Что есть на сайте

- Четыре кнопки с рандомными посланиями: «Я скучаю», «Люблю тебя», «Обними меня», «Сообщение».
- Галерея из трёх воспоминаний.
- Счётчик дней вместе.
- Секретный сюрприз в модальном окне.
- Адаптивная вёрстка для телефона и компьютера.
- Нежная розовая тема и плавающие сердечки.

## Перед публикацией обязательно настрой сайт

Открой `index.html` в редакторе кода и найди внизу блок:

```js
const SETTINGS = {
  relationshipStartDate: "2026-07-15",
  surpriseTitle: "Если вдруг ты забудешь…",
  surpriseMessage: "..."
};
```

1. Замени `2025-01-01` на дату начала ваших отношений в формате `ГГГГ-ММ-ДД`, например `2024-08-17`.
2. Перепиши `surpriseTitle` и `surpriseMessage` под себя.
3. При желании отредактируй сообщения в объекте `MESSAGES`.

Счётчик намеренно показывает сердечко вместо числа, пока не будет указана настоящая дата.

## Как добавить фотографии

1. Положи фотографии в папку `photos`.
2. Назови их точно `memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg`.
3. Если фотографии в PNG или WebP, измени расширения в атрибуте `src` соответствующего тега `<img>` в `index.html`.
4. В `index.html` найди карточки воспоминаний и замени заголовки и описания.

Используй фотографии, которыми тебе комфортно делиться: опубликованный сайт будет доступен всем, у кого есть ссылка, а саму ссылку можно переслать.

## Как посмотреть локально

Просто открой `index.html` в браузере. Никакой установки не требуется.

## Как бесплатно опубликовать через GitHub Pages

1. Войди на [GitHub](https://github.com/) и создай новый репозиторий, например `little-place-for-us`.
2. Для GitHub Free репозиторий должен быть публичным, если используешь обычный GitHub Pages.
3. Загрузи `index.html`, `README.md` и папку `photos` (с фотографиями, если уже добавила).
4. Открой репозиторий → **Settings** → **Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**.
6. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
7. Подожди несколько минут. На странице Pages появится ссылка вида `https://твой-логин.github.io/little-place-for-us/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Важно про приватность

GitHub Pages публикует сайт в открытом интернете. «По ссылке» означает, что сайт не спрятан за паролем: его могут открыть другие люди и переслать ссылку. Не публикуй адреса, документы или другую чувствительную информацию. Если нужна настоящая защита паролем, потребуется отдельный сервис с авторизацией.
